Chưa kết nối Supabase

Trang quản trị cần một cơ sở dữ liệu để lưu thống kê, thông báo và liên kết.

  1. Tạo dự án trên supabase.com.
  2. Mở SQL Editor, dán toàn bộ file supabase/schema.sql rồi chạy.
  3. Điền SUPABASE_URL và SUPABASE_ANON_KEY vào config.js ở thư mục gốc, rồi push lại.
